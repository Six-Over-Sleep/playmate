# AI

커뮤니티 서비스에서 사용하는 AI 기능을 개발하고 관리하는 폴더임.

머신러닝, 딥러닝, LLM, 파인튜닝 작업을 영역별로 분리하여 관리함.

## 폴더 구조

| 폴더 | 설명 |
|---|---|
| `ml/` | 머신러닝 모델 개발 영역임 |
| `dl/` | 딥러닝 모델 개발 영역임 |
| `llm/` | LLM, RAG, 챗봇 등 생성형 AI 기능 개발 영역임 |
| `fine_tuning/` | LLM 파인튜닝 및 학습 데이터 관리 영역임 |

```text
ai/
├─ ml/
├─ dl/
├─ llm/
├─ fine_tuning/
└─ README.md
```

## 폴더 설명

### `ml/`

Machine Learning 관련 작업을 저장함.

주요 작업 예시는 다음과 같음.

- 게시글 카테고리 분류
- 사용자 관심사 분석
- 게시글 추천
- 인기 게시글 예측
- 스팸 게시글 탐지

### `dl/`

Deep Learning 관련 작업을 저장함.

주요 작업 예시는 다음과 같음.

- 이미지 분류
- 텍스트 분류
- 분실물 이미지 분석
- PyTorch 기반 모델 개발

### `llm/`

Large Language Model을 활용한 기능을 개발함.

주요 작업 예시는 다음과 같음.

- 커뮤니티 챗봇
- RAG 기반 질의응답
- 게시글 요약
- 취업정보 요약
- 자격증 정보 질의응답
- 프롬프트 실험

### `fine_tuning/`

LLM 파인튜닝 관련 작업을 관리함.

주요 작업 예시는 다음과 같음.

- Fine-tuning Dataset 생성
- Instruction Dataset 작성
- LoRA / QLoRA 적용
- 학습 설정 관리
- 모델 학습 및 평가

## 관리 규칙

AI 관련 파일이 많아질 경우 각 폴더 내부에 다음과 같은 폴더를 추가할 수 있음.

```text
notebooks/
src/
models/
data/
outputs/
```

처음부터 과도하게 세분화하지 않고 필요한 시점에 추가함.

대용량 모델 파일은 GitHub에 직접 업로드하지 않는 것을 원칙으로 함.

# Collector Lambda에 함께 넣는 AWS SDK(boto3)와 그 의존성 (Issue #133). Processor에는 넣지 않는다.
#
# 왜 넣는가: Collector ZIP에는 requests 의존성인 urllib3가 들어간다. Lambda는 /var/task(ZIP)를 런타임
# 라이브러리보다 먼저 찾으므로, 런타임 boto3/botocore가 ZIP의 urllib3를 쓰게 된다. AWS 문서
# (https://docs.aws.amazon.com/lambda/latest/dg/python-package.html)는 이 경우 버전 불일치를 경고하고
# "SDK 의존성을 넣으면 boto3도 함께 넣으라"고 권장한다.
#
# 버전 결정: 아래 명령으로 기존 requirements-collector.txt 7개 버전을 고정한 채 boto3를 해결했다(2026-11-17).
#   uv pip compile --no-config --python-platform x86_64-manylinux_2_28 --python-version 3.13 \
#     --only-binary :all: --generate-hashes <7개 고정 + boto3>
#   → 13개 해결: 기존 7개는 그대로, 아래 6개 추가. urllib3 2.8.0은 botocore 1.44.4의 요구 범위를 만족.
# 이 6개는 프로젝트 uv.lock에 없다(프로젝트 의존성이 아니므로 uv.lock은 바꾸지 않는다).
# 해시는 패키지마다 PyPI 배포 파일 2개(wheel·sdist)의 값이다. --only-binary로 설치하므로 sdist는 쓰이지 않는다.

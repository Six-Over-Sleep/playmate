# PLAYMATE 부하 테스트 보고서

> 시험일: 2026-11-26
> 환경: AWS Production

## 1. 시험 목적

현재 운영 EC2가 베타 환경의 조회 요청을
안정적으로 처리하는지 검증한다.

## 2. 시험 환경

| 항목 | 설정 |
|---|---|
| EC2 | t3.small |
| CPU | 2 vCPU |
| RAM | 2 GiB |
| Swap | 2 GiB |
| EBS | gp3 20 GiB |
| DB | PostgreSQL 18 |
| DB Pool | 최대 2개 |
| 요청 경로 | Browser - CloudFront - Nginx - FastAPI - DB |
| 인증 | 단일 로그인 세션 |
| 테스트 방식 | 짧은 동시 요청 배치 |
| Timeout | 5초 |

## 3. 테스트 대상

    GET /api/boards

    GET /api/boards/2/posts?limit=20&offset=0&summary=true

조회 전용 DB Cursor 및 Service 계층의 읽기 로직을
확인한 후 테스트하였다.

## 10. 최종 평가

- 동시 요청 30개에서 두 API 모두 목표 성능을 충족하였다.
- 동시 요청 50개에서 오류는 없었으나 게시글 평균 응답시간이 목표를 초과하였다.
- 게시판 동시 요청 100개는 처리에 성공했으나 평균 및 P95 목표를 초과하였다.
- 현재 베타 운영에는 t3.small을 유지한다.
- DB Pool 2개의 연결 대기 가능성이 있으나 병목 원인은 확정되지 않았다.

## 11. 시험 제한사항

- 단일 로그인 계정 및 브라우저를 사용하였다.
- 브라우저의 요청 스케줄링이 측정 결과에 포함된다.
- 동시 요청 수를 실제 동시 접속자 수로 해석하지 않는다.
- 100개 테스트는 1회 배치만 수행하였다.
- 장시간 지속 부하 테스트는 미실시이다.
- 실제 게시글 데이터 건수는 확인되지 않았다.
- 게시글 작성, 파일 업로드, 로그인 부하는 제외하였다.
- 정확한 CPU, DB Pool 및 SQL 병목 분석은 추가 검증이 필요하다.

# Crawler

커뮤니티 서비스에서 자동으로 제공할 외부 데이터를 수집하는 폴더임.

현재 프로젝트에서는 맛집 정보, IT 뉴스, 취업정보 등을 수집함.

## 폴더 구조

| 폴더 | 설명 |
|---|---|
| `restaurant/` | 맛집 정보 수집 영역임 |
| `it_news/` | IT 뉴스 수집 영역임 |
| `jobs/` | 취업정보 및 채용공고 수집 영역임 |
| `data/` | 크롤링 결과 데이터 저장 영역임 |

```text
crawler/
├─ restaurant/
├─ it_news/
├─ jobs/
├─ data/
└─ README.md
```

## 폴더 설명

### `restaurant/`

맛집 관련 데이터를 수집함.

주요 수집 데이터는 다음과 같음.

- 매장명
- 주소
- 카테고리
- 평점
- 리뷰
- 위치 정보
- 도보 관련 정보

### `it_news/`

IT 관련 뉴스 데이터를 수집함.

주요 수집 데이터는 다음과 같음.

- 뉴스 제목
- 기사 URL
- 언론사
- 작성일
- 기사 요약

### `jobs/`

취업 및 채용 관련 데이터를 수집함.

주요 수집 데이터는 다음과 같음.

- 기업명
- 채용 제목
- 직무
- 모집 기간
- 마감일
- 채용공고 URL

### `data/`

크롤링 결과 데이터를 저장함.

CSV, JSON 등의 데이터를 저장할 수 있음.

데이터가 많아질 경우 다음과 같이 분리함.

```text
data/
├─ raw/
└─ processed/
```

`raw/`는 수집 직후의 원본 데이터를 저장하는 영역임.

`processed/`는 정제 및 가공이 완료된 데이터를 저장하는 영역임.

## 관리 규칙

크롤링 코드와 데이터베이스 생성 코드는 분리함.

원본 데이터와 가공 데이터를 구분하여 관리함.

동일 데이터가 중복 저장되지 않도록 확인함.

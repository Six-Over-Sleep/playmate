# Docs

커뮤니티 개발 프로젝트에서 사용하는 각종 문서를 관리하는 폴더임.

설계 문서, 검수 자료, 최종 제출 자료를 목적에 따라 구분하여 관리함.

## 폴더 구조

| 폴더 | 설명 |
|---|---|
| `design/` | 프로젝트 설계 문서 관리 영역임 |
| `qa/` | 기능 테스트 및 검수 자료 관리 영역임 |
| `deliverables/` | 보고서, 발표자료 등 최종 산출물 관리 영역임 |

```text
docs/
├─ design/
├─ qa/
├─ deliverables/
└─ README.md
```

## 폴더 설명

### `design/`

서비스를 어떤 구조와 방식으로 개발할 것인지 정의한 설계 자료를 저장함.

주요 문서는 다음과 같음.

```text
요구사항정의서.xlsx
ERD.png
테이블정의서.xlsx
API명세서.xlsx
화면설계서.pdf
시스템구성도.png
```

다음과 같은 자료가 해당됨.

- 요구사항 정의
- ERD
- 데이터베이스 설계
- API 설계
- UI / UX 설계
- 시스템 아키텍처
- 화면 시안

### `qa/`

개발한 기능이 요구사항에 맞게 정상적으로 동작하는지 확인한 검수 자료를 저장함.

주요 문서는 다음과 같음.

```text
기능테스트.xlsx
검수체크리스트.xlsx
버그목록.xlsx
수정내역.md
```

다음과 같은 자료가 해당됨.

- 기능 테스트
- 통합 테스트
- 검수 체크리스트
- 오류 목록
- 버그 수정 내역

### `deliverables/`

프로젝트의 제출용 문서 및 최종 산출물을 저장함.

주요 문서는 다음과 같음.

```text
프로젝트계획서.docx
역할분담표.xlsx
중간보고서.docx
최종보고서.pdf
최종발표자료.pptx
발표대본.docx
```

다음과 같은 자료가 해당됨.

- 프로젝트 계획서
- 역할분담 자료
- 중간 보고서
- 최종 보고서
- 발표자료
- 발표대본
- 최종 제출 파일

## 관리 규칙

설계 단계의 문서와 최종 제출 문서를 구분하여 관리함.

문서가 많아질 경우에만 다음과 같이 추가 세분화함.

```text
design/
├─ database/
├─ api/
├─ requirements/
└─ ui-ux/
```

현재 단계에서는 `design`, `qa`, `deliverables` 세 폴더를 기준으로 관리함.

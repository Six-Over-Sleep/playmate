# 모임 DB 통합 (#157) — 042/043

## 📌 작업 개요

모임 유형별 상세 테이블 4개와 커리큘럼 테이블 1개를 통합하여
물리 테이블 수를 줄이고 백엔드 저장·조회 구조를 개선했습니다.

기존 API 및 데이터 호환성을 유지하기 위해
삭제 대상 테이블 이름을 호환 뷰(View)로 전환했습니다.

## 🛠️ DB 변경 사항

### 1. 모임 상세 테이블 통합 (042)

기존 물리 테이블:

- `recruit_sports_details`
- `recruit_game_details`
- `recruit_study_details`
- `recruit_group_buy_details`

변경 사항:

- 상세 정보를 `recruits.details(JSONB)`에 통합
- 기존 데이터 이관
- 기존 테이블명을 호환 뷰로 유지
- INSERT, UPDATE, DELETE 지원 트리거 추가
- JSONB 데이터 제약조건 및 값 검증 추가

### 2. 모임 커리큘럼 통합 (043)

기존 물리 테이블:

- `recruit_curricula`

변경 사항:

- 커리큘럼 데이터를 `recruit_programs`로 통합
- 커리큘럼 관련 컬럼 추가
- 기존 테이블명을 호환 뷰로 유지
- 커리큘럼 저장·수정 및 버전 관리 구조 개선

## ⚠️ 운영 및 마이그레이션 주의사항

1. SQL 042와 043은 최초 통합을 위한 일회성 마이그레이션입니다.
2. 이미 적용된 Aiven DB에 동일 SQL을 재실행하지 않습니다.
3. AWS RDS는 별도의 적용 및 검증이 필요합니다.
4. 적용 전 대상 DB의 선행 마이그레이션 상태와 백업을 확인합니다.
5. 모임 API 변경 코드는 대상 DB 마이그레이션과 호환되는 상태에서 배포해야 합니다.
6. GitHub Actions의 AWS 자동 배포 여부를 Merge 전에 확인해야 합니다.
7. 기존 호환 뷰는 모든 호출부의 전환을 확인하기 전까지 유지합니다.
8. 운영 환경에서 기존 baseline SQL 또는 `create_all`을 재실행하지 않습니다.
